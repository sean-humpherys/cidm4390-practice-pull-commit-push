# cidm4390-practice-pull-commit-push
Make a copy of the "template.md" file. Rename the "template.md" file to include your initials, e.g., "slh.md". Every student should have a unique MD file. 

Edit only your markdown file please. We are not learning how to resolve merge conflicts yet. Insert AI answer to your daily questions after the question. Use markdown to format this file. 

Purpose: For us to practice git pull, make edits, git add, git commit, git push, and git status. Do not use GitHub's online editor to edit the markdown files as that is counter productive to the learning objectives. 

To view markdown files in VS Code, press CTRL+SHIFT+V

Read the exact [assignment instructions](https://docs.google.com/document/d/1PTodUPdk0Xmqe8tan-tljWxrATjYl37Xclb1l6_M21E/edit?tab=t.0)

Edit only your markdown file which has your initials. Edit one daily question each of five days. Each day issue the following commands from a terminal in VS Code. 

    git pull
    make your edits
    git add -A
    git commit -m ‘Day X answered’
    git push
    git status
